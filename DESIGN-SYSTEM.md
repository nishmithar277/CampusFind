# CampusFind Design System

## Colors
- Primary: `#2563EB` — buttons and main actions
- Secondary: `#17345C` — navigation and brand areas
- Background: `#F7F9FC` — page background
- Text: `#172033` — headings and body text
- Muted text: `#64748B` — supporting text
- Accent: `#EAF1FF` — tags and secondary action backgrounds
- Error: `#B91C1C`
- Success: `#15803D`

## Typography
- Font family: Arial, sans-serif
- H1: 36–42px, bold
- H2: 24px, bold
- H3: 18px, bold
- Body: 16px, regular
- Small/secondary: 13–14px, regular
- Buttons: 14–16px, semibold

## Reusable UI Components
- Navbar: primary navigation and login/logout
- Button: primary and secondary actions
- ItemCard: reusable lost/found report card
- Input: text and email fields
- Dropdown: item type and category selection
- EmptyState: message when there are no reports
- Notice: helper information for demo login

## Layout
- Responsive card grid
- Maximum content width: 1050px
- Rounded cards and form controls
- Consistent spacing and clear labels
