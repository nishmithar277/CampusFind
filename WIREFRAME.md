# CampusFind Wireframe (low-fidelity)

Use this as a guide to draw the actual wireframe in Figma, Excalidraw, or on paper and export an image/PDF for submission.

## Navigation
`Logo | Home | Lost Items | Found Items | Report | Login / Logout`

## Home page
```text
+--------------------------------------------------+
| CampusFind       Home Lost Found Report Login    |
+--------------------------------------------------+
| CAMPUS LOST & FOUND                               |
| Lost something on campus?                         |
| Short explanation                                 |
| [Report an item] [Browse lost items]              |
+--------------------------------------------------+
| Recent reports                                    |
| [Item card] [Item card] [Item card]               |
+--------------------------------------------------+
```

## Login page


## Lost / Found listing
```text
+--------------------------------------------------+
| Lost items / Found items                          |
| [Item card] [Item card] [Item card]               |
| Item name | Type | Location | Description         |
| [Contact]                                        |
+--------------------------------------------------+
```

## User flow
`Home → Login/Register → Report item → Submit → Lost or Found listing → Contact`
